# 📦 ArmazingXStock

Sistema de gerenciamento de estoque e endereçamento de armazéns desenvolvido em **C# e .NET**.

## 🎯 Sobre o projeto

O projeto tem como objetivo controlar produtos, fornecedores, posições e movimentações de estoque.

A estrutura de endereçamento segue:

**Armazém → Corredor → Rua → Módulo → Nível → Endereço**

## 🛠️ Tecnologias e conceitos

- C# / .NET
- ASP.NET Core Web API
- Programação Orientada a Objetos
- PK e FK
- Relacionamentos e propriedades de navegação
- Collections e Enums
- Git / GitHub
